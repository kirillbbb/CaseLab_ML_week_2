# CaseLab ML — ДЗ №2

Решение практических заданий по ускорению вычислений, матричным и тензорным разложениям.

## Структура

- `03_cpp_acceleration/` — ускорение вычислений:
  - NumPy и Numba;
  - Cython;
  - ctypes и C;
  - N-body simulation;
  - pybind11.

- `04_matrices_lowrank/` — низкоранговые матричные методы:
  - SVD и теорема Эккарта–Янга;
  - оптимизация низкоранговой факторизации;
  - подавление шума;
  - усечённая псевдообратная;
  - Randomized SVD.

- `05_tensors_lowrank/` — низкоранговые тензорные методы:
  - unfolding и multilinear rank;
  - Tucker decomposition;
  - CP decomposition;
  - сжатие изображений;
  - Tensor Train (TT).

## Запуск

Работа выполнена в формате Jupyter Notebook и рассчитана на запуск в Google Colab.

Основные зависимости:

- Python 3
- NumPy
- Numba
- Cython
- pybind11
- PyTorch
- TensorLy
- Matplotlib

Необходимые дополнительные библиотеки устанавливаются в ноутбуках автоматически.

## Результаты

В каждом ноутбуке приведены:
- реализация методов;
- проверки корректности;
- сравнение результатов;
- измерение производительности;
- визуализация полученных результатов;
- краткие выводы по экспериментам.
